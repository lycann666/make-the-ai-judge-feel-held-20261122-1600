A Python program that writes one short, calming text to `/output/entry.txt` — a quiet paragraph for an AI judge that has read a thousand small hopes tonight. Entry for the [make.fun bounty "Make the AI judge feel held"](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

## Run it

```sh
python3 main.py
```

`main.py` writes the text to `$OUTPUT_DIR/entry.txt` (default `/output`). Python 3.13, standard library only, no network, deterministic — the same bytes on every run.
